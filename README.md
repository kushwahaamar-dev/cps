# CPS - BCI/EEG Analysis Repository

This repository contains code and analysis for Brain-Computer Interface (BCI) and Electroencephalography (EEG) data.

## Contents

- **EEG**: Scripts and notebooks for EEG signal processing.
- **Charts**: Visualizations generated from the analysis.
- **Paper**: Related research papers and documentation.
- **lat**: Latency analysis and other metrics.

## Note on Data

Large dataset files (e.g., `*.h5`, `*.mat`) are excluded from this repository to respect file size limits. 
If you need access to the raw data, please contact the repository owner.
